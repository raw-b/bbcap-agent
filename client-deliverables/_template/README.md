Client Deliverables — Template
Each client gets a copy of this folder. Naming convention: client-deliverables/[client-name]/

Files Created During Standard BBCAP Workflow
Stage	File	Description
Pre-work	transcript-source.md	Discovery call transcript(s), placed here before beginning
1	stage-1-transcript-mining.md	Status quo language, failed alternatives, unique approach signals, proof points, transformation language, tensions
2	stage-2-syllogism-candidates.md	2-3 candidate syllogisms with validation tests and recommendation
3	stage-3-core-melody-versions.md	Bullet, short prose, and one-pager versions of the Core Melody Argument
4	stage-4-belief-map-content-starter.md	Belief Transformation Map + Marketing Content Starter List (spreadsheet-ready)
Cross-Agent Visibility
When COO-per-client is active, it reads this folder to determine engagement status. The presence and completeness of these stage files signals where the client is in the BBCAP workflow.
